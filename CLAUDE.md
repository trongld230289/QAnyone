# QAnyone — Playwright E2E automation framework

This repository is a Playwright test project driven by the QAnyone framework.

**Before responding to ANY message, READ `QAnyone/core.md` and follow it.**
It tells you which other `QAnyone/*.md` file to read for the current command. Read them again
for every command, even if you read them earlier in this chat: `npx … update` replaces them and
long chats drop earlier reads.

- Never edit files under `QAnyone/` — they are the framework.
- Never commit, never print secret values. Write to Azure DevOps only when the user picks it in
  a QAnyone dialog.
