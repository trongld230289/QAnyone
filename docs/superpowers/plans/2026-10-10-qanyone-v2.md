# QAnyone v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1 QAnyone package with a Playwright-only, Copilot Chat + Claude Code framework where ADO, free-form markdown and codegen test cases all normalize to one markdown format and run through one pipeline.

**Architecture:** The package is 5 English instruction files (`core / setup / pipeline / formats / rules`), one offline HTML setup form, and TypeScript templates + 2 ADO scripts that get copied into a user's empty test repo. Instruction files use abstract verbs (ASK / RUN / READ / WRITE / BROWSER) mapped to real tools in one table in `core.md`. A dev-only `tools/` folder in this repo lints the package (size budget, forbidden strings, broken links) and tests the form, templates and scripts.

**Tech Stack:** Markdown, vanilla HTML/JS (no CDN), TypeScript, `@playwright/test`, `@playwright/mcp`, `dotenv`, `tsx`, Node ≥ 18 (`node:test`, global `fetch`).

**Spec:** `docs/superpowers/specs/2026-10-10-qanyone-v2-design.md`

## Global Constraints

- Work on branch `v2-design` (already exists, contains the spec). Never commit to `main`.
- Package = exactly: `CLAUDE.md`, `.github/copilot-instructions.md`, `QAnyone/**`. Everything else in this repo (`tools/`, `docs/`, `README.md`, `package.json`) is dev-only and is never copied to user repos.
- Instruction files are **English**. TC content language is a config value (`language: vi | en`).
- Size budget (chars, ≈ 4 chars/token): `core.md ≤ 11 000`, `setup.md ≤ 9 000`, `pipeline.md ≤ 17 000`, `formats.md ≤ 9 000`, `rules.md ≤ 9 000`. Sum of the five ≤ 55 000.
- Forbidden anywhere in the repo (case-insensitive): `cypress`, `waitForTimeout`, `expect.soft`, mojibake `â€`, `Ã`, plus every private identifier (former employer name, internal ADO org/project, internal hostnames, machine paths, v1 workspace folder names) listed in the git-ignored `tools/forbidden.local`.
- Locator source tags are exactly: `[FROM MCP]`, `[FROM CODEGEN]`, `[FROM USER]`, `[FROM TEMPLATE]` (the last one only for vendor login pages shipped in templates).
- Self-heal limit is **3** everywhere. Retry count 5 must not appear.
- Commands are uppercase: `SETUP`, `NEW TC`, `RERUN TC`, `STATUS`, `PUSH ADO`. No other commands.
- Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Files must be UTF-8 without BOM, LF line endings (add `.gitattributes` in Task 3).

- [ ] **Step 2: Write the lint**

`tools/check-package.mjs`:
```js
import { readFileSync, existsSync, readdirSync, statSync } from "node:fs";
import { join, dirname, resolve } from "node:path";

const ROOT = resolve(dirname(new URL(import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, "$1")), "..");
const REQUIRED = [
  "CLAUDE.md", ".github/copilot-instructions.md",
  "QAnyone/core.md", "QAnyone/setup.md", "QAnyone/pipeline.md", "QAnyone/formats.md", "QAnyone/rules.md",
  "QAnyone/setup/index.html", "QAnyone/templates/test-case.md",
  "QAnyone/templates/playwright.config.ts", "QAnyone/templates/auth.setup.ts",
  "QAnyone/templates/base.page.ts", "QAnyone/templates/page.template.ts",
  "QAnyone/templates/login.form.page.ts", "QAnyone/templates/login.azure-ad.page.ts", "QAnyone/templates/login.google.page.ts",
  "QAnyone/templates/pages.fixture.ts", "QAnyone/templates/env.ts", "QAnyone/templates/totp.ts",
  "QAnyone/templates/env.example", "QAnyone/templates/gitignore",
  "QAnyone/templates/mcp.json", "QAnyone/templates/vscode-mcp.json",
  "QAnyone/templates/scripts/fetch-tc.ts", "QAnyone/templates/scripts/ado-writer.ts",
];
const BUDGET = { "QAnyone/core.md": 11000, "QAnyone/setup.md": 9000, "QAnyone/pipeline.md": 17000, "QAnyone/formats.md": 9000, "QAnyone/rules.md": 9000 };
const TOTAL_BUDGET = 55000;
const FORBIDDEN = [/cypress/i, /waitForTimeout/, /expect\.soft/, /â€/, /Ã/, /TODO/, /TBD/]; // + patterns from git-ignored tools/forbidden.local
const SKIP_DIRS = new Set(["node_modules", ".git", "docs", "test-results", "playwright-report"]);

const errors = [];
for (const f of REQUIRED) if (!existsSync(join(ROOT, f))) errors.push(`missing: ${f}`);

function walk(dir, out = []) {
  for (const e of readdirSync(dir)) {
    if (SKIP_DIRS.has(e)) continue;
    const p = join(dir, e);
    statSync(p).isDirectory() ? walk(p, out) : out.push(p);
  }
  return out;
}
const textFiles = walk(ROOT).filter(p => /\.(md|html|ts|json|example|mjs|sh|yml|yaml)$|\/gitignore$|\/env\.example$/.test(p.replace(/\\/g, "/")));

let total = 0;
for (const p of textFiles) {
  const rel = p.slice(ROOT.length + 1).replace(/\\/g, "/");
  const buf = readFileSync(p);
  if (buf[0] === 0xef && buf[1] === 0xbb && buf[2] === 0xbf) errors.push(`BOM: ${rel}`);
  const txt = buf.toString("utf8");
  if (txt.includes("\r\n")) errors.push(`CRLF: ${rel}`);
  for (const re of FORBIDDEN) if (re.test(txt) && !rel.startsWith("tools/")) errors.push(`forbidden ${re}: ${rel}`);
  if (BUDGET[rel] !== undefined) {
    total += txt.length;
    if (txt.length > BUDGET[rel]) errors.push(`over budget ${txt.length}>${BUDGET[rel]}: ${rel}`);
  }
  if (rel.endsWith(".md")) {
    for (const m of txt.matchAll(/\]\((?!https?:|#)([^)]+)\)/g)) {
      const target = m[1].split("#")[0];
      if (target && !existsSync(resolve(dirname(p), target))) errors.push(`broken link ${m[1]} in ${rel}`);
    }
  }
}
if (total > TOTAL_BUDGET) errors.push(`instruction total ${total} > ${TOTAL_BUDGET}`);

if (errors.length) { console.error(errors.join("\n")); process.exit(1); }
console.log(`check-package OK (${textFiles.length} files, instruction chars ${total})`);
```

```markdown
You are an AI agent that writes and maintains Playwright end-to-end tests for ONE web

2. If `phase != ready` or `current_tc` is set → continue from `current_step` (see pipeline.md).

## Commands
| Command | Context file | What happens |
|---|---|---|
| `SETUP` | setup.md | First-time scaffold, import of an existing Playwright repo, or resume — auto-detected |
| `NEW TC <ADO id>` | pipeline.md | Fetch test case from Azure DevOps, build and run the test |
| `NEW TC <path.md>` | pipeline.md | Normalize a free-form markdown test case file (may hold several TCs) |
| `NEW TC <name>` | pipeline.md | Record the flow with codegen, then build and run the test |
| `RERUN TC <id>` | pipeline.md | Re-run one test; regenerate spec first if its TC file changed |
| `STATUS` | — | Print phase, auth state, TC list with status, registry counts |
| `PUSH ADO <id>` | pipeline.md | Create/update the test case on Azure DevOps after a preview |

Several ids: `NEW TC 101 102 103` → run the pipeline per id, sequentially.
Anything else → answer briefly and show this table. Do not start work without a command.

## Platform map
Instruction files use abstract verbs. Translate with this table.
| Verb | Copilot Chat | Claude Code |
|---|---|---|
| ASK | `ask_questions` | `AskUserQuestion` |
| RUN | `run_in_terminal` | `Bash` |
| RUN BACKGROUND | `run_in_terminal` + `isBackground: true` | `Bash` + `run_in_background: true` |
| READ / WRITE / EDIT | `read_file` / `create_file` / `replace_string_in_file` | `Read` / `Write` / `Edit` |
| SEARCH | `file_search`, `grep_search` | `Glob`, `Grep` |
| BROWSER | `mcp_playwright_browser_*` | `mcp__playwright__browser_*` |
| Instruction file | `.github/copilot-instructions.md` | `CLAUDE.md` |
| MCP config | `.vscode/mcp.json` | `.mcp.json` |

ASK is used in exactly three places: SETUP when a state file already exists, CONFIRM after
NORMALIZE, and the preview before PUSH ADO. Every ASK has a fallback: tell the user which file
to edit and to type `OK` when done. Never put a terminal command inside an ASK — the user
cannot copy from a dialog; run it yourself.

BROWSER requires the Playwright MCP server (`@playwright/mcp`). If its tools are not available:
say exactly what to enable (the MCP config file for this platform, then restart) and stop.
Do not substitute DOM-dump scripts, `page.evaluate`, or guessed locators.

## Hard rules
1. Never guess a locator. Sources: pom-registry → TC Locators table → BROWSER. Tag every locator.
2. Auth first: no feature POM or spec until `auth_ready: true` (when the app needs login).
3. One TC = one file in `test-cases/` = source of truth. Specs are generated from it.
4. Read only what the current step needs: `core.md` + one context file + `pom-registry/INDEX.md`
   + the registry file(s) of the features touched.
5. WRITE `QANYONE_STATE.md` after every pipeline step and before stopping for any reason.
6. Never commit. Never push to ADO except in `PUSH ADO`. Never write secret values into
   markdown or chat; `.env` stays in `.gitignore`.
7. Self-heal at most 3 rounds, only with the allowed fixes in `rules.md`.
8. Do not add features, tests or files the user did not ask for.

## Errors
Non-blocking → fix and retry yourself, do not ask:
- Write fails because content is too long → split the file into 2–3 WRITE/EDIT calls; never
  retry the same size.
- Command fails / TypeScript error / test fails → read the error, fix, rerun (test: ≤ 3 rounds).
- Response was cut off → continue from where it stopped; do not restart.

Blocking → WRITE state, explain what is blocked and what the user must do, then stop:
- Login cannot be completed (expired credentials, unsupported MFA, CAPTCHA).
- ADO id does not exist, or ADO returns 401/403.
- A locator cannot be resolved even through BROWSER, and the TC gives no disambiguating context.
- Base URL unreachable.

## Files
Framework (read-only): `QAnyone/**`, `CLAUDE.md`, `.github/copilot-instructions.md`.
Generated by you (see formats.md): `qanyone.config.md`, `QANYONE_STATE.md`, `test-cases/`,
`pom-registry/`, `pages/`, `fixtures/`, `tests/`, `helpers/`, `scripts/`, `playwright.config.ts`.
```

```markdown
# QAnyone rules — read before writing any POM or spec

## Locator
- Never guess. Allowed sources, cheapest first: `pom-registry` → TC `Locators` table →
  BROWSER (`browser_snapshot` on the page, then `browser_generate_locator` for the element;
  if that tool is missing, derive from the snapshot's role + name).
- Tag every locator: `[FROM MCP]` `[FROM CODEGEN]` `[FROM USER]` `[FROM TEMPLATE]`.
- Priority: `getByRole` > `getByLabel` > `getByPlaceholder` > `getByText` > `getByTestId` > CSS.
  CSS only when BROWSER confirms nothing else is unique.
- Repeated names (one "Delete" per row, one checkbox per row): scope by container —
  `page.getByRole('row', { name: 'Job A' }).getByRole('button', { name: 'Delete' })` or
  `.filter({ hasText })`. Never `.nth()` unless the TC literally says "row N".
  If the TC gives no context to choose → BLOCKING: ask the user which one.
- Never write Node scripts, `page.evaluate`, or DOM dumps to find locators.
- Keep a locator in exactly one place: the POM. Specs use POM methods or locators from the
  fixture-provided page object; inline locators only for one-off assertions.

## Action
- `Check` → `.check()`, `Uncheck` → `.uncheck()`. Never `.click()` on a checkbox (click toggles
  blindly; check/uncheck are idempotent).
- `Select` → `.selectOption()` for `<select>`; for custom dropdowns: click trigger, then
  `getByRole('option', { name })`.
- `Press` → `locator.press('Enter')` on the focused element, or `page.keyboard.press`.
- `Navigate` → `page.goto(path)` then `await expect(page).toHaveURL(...)`.
- Wait only with `expect(...).toBeVisible()`, `toHaveURL`, `waitForURL`, `waitForResponse`.
  Hard sleeps are forbidden everywhere, including "to make the video readable" — the config
  already records `trace: 'on-first-retry'` and `video: 'retain-on-failure'`.

### Known-hard patterns (wrong *action*, not wrong locator — BROWSER will not fix these)
| Pattern | Symptom | Correct code |
|---|---|---|
| Native dialog (`alert/confirm/prompt`) | script hangs forever | register `page.on('dialog', d => d.accept())` **before** the triggering action |
| File upload | replay opens the OS file picker | `locator.setInputFiles(path)` — never click the input |
| File download | test passes but nothing verified | `const [dl] = await Promise.all([page.waitForEvent('download'), trigger])` |
| iframe | "element not found" though visible | `page.frameLocator(sel).getByRole(...)` |
| New window / popup | clicks go to the old tab | `const [popup] = await Promise.all([page.waitForEvent('popup'), trigger])` |
| HTML5 drag & drop | `.dragTo()` runs, UI unchanged | dispatch `dragstart` / `dragover` / `drop` manually |
| Open shadow DOM | usually fine | normal locators pierce open roots; only escalate when it really fails |
| Closed shadow DOM | nothing can see it | BLOCKING — tell the user it needs `data-testid` from the dev team |

## Assertion
- Every non-empty Expected in the TC → at least one real `expect()` in the spec.
- No `expect.soft`, no `try/catch` around locators or assertions, no `test.skip`/`test.fixme`.
- POM classes contain no assertions; specs do.
- Prefer `toBeVisible`, `toHaveText`, `toContainText`, `toHaveURL`, `toHaveCount`, `toBeChecked`.

## Self-heal (max 3 rounds per test run)
Allowed fixes
- Locator wrong/ambiguous → re-discover through BROWSER on the live page, update POM + registry.
- Missing wait → add the right `expect`/`waitForURL` before the failing action.
- Wrong verb mapping (e.g. click on checkbox) → fix the action.
- Test data typo → fix Test Data in the TC file, regenerate the spec.

Forbidden fixes
- Weakening, removing or commenting out an assertion; changing an Expected to match the app.
- Hard sleeps, `expect.soft`, `try/catch`, `test.skip`/`fixme`, skipping a step.
- Increasing timeouts above 2× the default without a BROWSER-confirmed slow load.

After 3 failed rounds, or when the failure looks like an app bug or a wrong TC:
set `status: blocked`, write the reason + trace/screenshot path into the TC `Notes`, report.
Never report a blocked test as fixed.

## POM and spec shape
POM (`pages/<name>.page.ts`): one class per page; `readonly` locators assigned in the
constructor; methods are business actions (`search(keyword)`, `openJob(name)`); `goto()` uses a
path relative to `baseURL`. Register new pages in `fixtures/pages.fixture.ts`.
Spec (`tests/<feature>/<id>-<slug>.spec.ts`): `test.describe('<id> <title>', { tag: ['@regression'] })`,
one `test()` per TC, one `test.step('<n>. <Action>')` per TC row, data from a `const data = {...}`
block generated from Test Data. Use the fixture (`async ({ jobsPage }) =>`), not `new JobsPage(page)`.
```

```ts
import { createHmac } from "node:crypto";

const ALPHABET = "ABCDEFGHIJKLMNOPQRSTUVWXYZ234567";

function base32Decode(input: string): Buffer {
  const clean = input.toUpperCase().replace(/[^A-Z2-7]/g, "");
  const bytes: number[] = [];
  let bits = 0, value = 0;
  for (const ch of clean) {
    value = (value << 5) | ALPHABET.indexOf(ch);
    bits += 5;
    if (bits >= 8) { bytes.push((value >>> (bits - 8)) & 0xff); bits -= 8; }
  }
  return Buffer.from(bytes);
}

/** RFC 6238 TOTP, SHA-1, 6 digits, 30 s step. `now` in ms (default Date.now()). */
export function generateTotp(secret: string, now: number = Date.now()): string {
  const counter = Math.floor(now / 1000 / 30);
  const msg = Buffer.alloc(8);
  msg.writeBigUInt64BE(BigInt(counter));
  const hmac = createHmac("sha1", base32Decode(secret)).update(msg).digest();
  const offset = hmac[hmac.length - 1] & 0x0f;
  const code = ((hmac[offset] & 0x7f) << 24 | hmac[offset + 1] << 16 | hmac[offset + 2] << 8 | hmac[offset + 3]) % 1_000_000;
  return code.toString().padStart(6, "0");
}
```

```ts
#!/usr/bin/env -S npx tsx
/** Fetch an Azure DevOps test case and print { id, title, steps } as JSON. */
import "dotenv/config";

export type AdoEnv = { org: string; project: string; pat: string };
export type Step = { index: number; action: string; expected: string };

export function adoEnv(): AdoEnv {
  const get = (k: string) => { const v = process.env[k]; if (!v) throw new Error(`Missing ${k} in .env`); return v; };
  return { org: get("ADO_ORG").replace(/\/$/, ""), project: get("ADO_PROJECT"), pat: get("ADO_PAT") };
}

export function authHeaders(pat: string): Record<string, string> {
  return { Authorization: "Basic " + Buffer.from(":" + pat).toString("base64"), "Content-Type": "application/json-patch+json" };
}

const decodeEntities = (s: string) => s
  .replace(/&lt;/g, "<").replace(/&gt;/g, ">").replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&nbsp;/g, " ").replace(/&amp;/g, "&");

export function htmlToText(html: string): string {
  const decoded = decodeEntities(html);
  return decodeEntities(decoded.replace(/<br\s*\/?>/gi, " ").replace(/<[^>]+>/g, " ")).replace(/\s+/g, " ").trim();
}

export function parseSteps(xml: string): Step[] {
  const steps: Step[] = [];
  const re = /<step\b[^>]*>([\s\S]*?)<\/step>/g;
  let m: RegExpExecArray | null;
  while ((m = re.exec(xml))) {
    const parts = [...m[1].matchAll(/<parameterizedString[^>]*>([\s\S]*?)<\/parameterizedString>/g)].map(p => htmlToText(p[1]));
    steps.push({ index: steps.length + 1, action: parts[0] ?? "", expected: parts[1] ?? "" });
  }
  return steps;
}

export async function fetchTestCase(id: number, env: AdoEnv, fetchImpl: typeof fetch = fetch) {
  const url = `${env.org}/${encodeURIComponent(env.project)}/_apis/wit/workitems/${id}?api-version=7.1`;
  const res = await fetchImpl(url, { headers: authHeaders(env.pat) });
  if (res.status === 404) throw new Error(`ADO test case ${id} not found`);
  if (!res.ok) throw new Error(`ADO ${res.status}: ${await res.text()}`);
  const json = await res.json() as { id: number; fields: Record<string, string> };
  return { id: json.id, title: json.fields["System.Title"] ?? "", steps: parseSteps(json.fields["Microsoft.VSTS.TCM.Steps"] ?? "") };
```

```ts
#!/usr/bin/env -S npx tsx
/** Create or update an Azure DevOps test case from "action::expected|action::expected" steps. */
import "dotenv/config";
import { adoEnv, authHeaders, type AdoEnv } from "./fetch-tc";

export type StepIn = { action: string; expected: string };

const esc = (s: string) => s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");

export function buildStepsXml(steps: StepIn[]): string {
  const inner = steps.map((s, i) => {
    const id = i + 2, type = s.expected ? "ValidateStep" : "ActionStep";
    return `<step id="${id}" type="${type}"><parameterizedString isformatted="true">&lt;DIV&gt;&lt;P&gt;${esc(esc(s.action))}&lt;/P&gt;&lt;/DIV&gt;</parameterizedString><parameterizedString isformatted="true">&lt;DIV&gt;&lt;P&gt;${esc(esc(s.expected))}&lt;/P&gt;&lt;/DIV&gt;</parameterizedString><description/></step>`;
  }).join("");
  return `<steps id="0" last="${steps.length + 1}">${inner}</steps>`;
}

export function parseStepsArg(arg: string): StepIn[] {
  return arg.split("|").map(p => { const [action, expected = ""] = p.split("::"); return { action: action.trim(), expected: expected.trim() }; }).filter(s => s.action);
}

export async function createTestCase(input: { title: string; steps: StepIn[]; userStoryId?: number }, env: AdoEnv, fetchImpl: typeof fetch = fetch): Promise<number> {
  const ops: object[] = [
    { op: "add", path: "/fields/System.Title", value: input.title },
    { op: "add", path: "/fields/Microsoft.VSTS.TCM.Steps", value: buildStepsXml(input.steps) },
  ];
  if (input.userStoryId) ops.push({ op: "add", path: "/relations/-", value: { rel: "Microsoft.VSTS.Common.TestedBy-Reverse", url: `${env.org}/${encodeURIComponent(env.project)}/_apis/wit/workItems/${input.userStoryId}` } });
  const url = `${env.org}/${encodeURIComponent(env.project)}/_apis/wit/workitems/$Test%20Case?api-version=7.1`;
  const res = await fetchImpl(url, { method: "POST", headers: authHeaders(env.pat), body: JSON.stringify(ops) });
  if (!res.ok) throw new Error(`ADO ${res.status}: ${await res.text()}`);
  return (await res.json() as { id: number }).id;
}

export async function updateTestCase(id: number, steps: StepIn[], env: AdoEnv, fetchImpl: typeof fetch = fetch): Promise<number> {
  const ops = [{ op: "add", path: "/fields/Microsoft.VSTS.TCM.Steps", value: buildStepsXml(steps) }];
  const url = `${env.org}/${encodeURIComponent(env.project)}/_apis/wit/workitems/${id}?api-version=7.1`;
  const res = await fetchImpl(url, { method: "PATCH", headers: authHeaders(env.pat), body: JSON.stringify(ops) });
  if (!res.ok) throw new Error(`ADO ${res.status}: ${await res.text()}`);
  return (await res.json() as { id: number }).id;
}

if (process.argv[1] && /ado-writer\.ts$/.test(process.argv[1])) {
  const [cmd, ...rest] = process.argv.slice(2);
  const arg = (k: string) => { const i = rest.indexOf(k); return i >= 0 ? rest[i + 1] : undefined; };
  const steps = parseStepsArg(arg("--steps") ?? "");
  const run = cmd === "create"
    ? createTestCase({ title: arg("--title") ?? "", steps, userStoryId: arg("--us") ? Number(arg("--us")) : undefined }, adoEnv())
    : cmd === "update" ? updateTestCase(Number(arg("--tc")), steps, adoEnv())
    : Promise.reject(new Error('usage: ado-writer.ts create --title "<t>" --steps "a::e|a::e" [--us <id>] | update --tc <id> --steps "..."'));
  run.then(id => console.log(JSON.stringify({ id }))).catch(e => { console.error(e.message); process.exit(1); });
}
```
